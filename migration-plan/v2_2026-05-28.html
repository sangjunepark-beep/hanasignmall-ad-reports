3대표 의도 vs 데이터

⚠ 데이터가 보여주는 사실

  • .com이 광고비 1원당 매출 더 높음 (390% vs 282%)
  • 단순 이전 = 효율 자동 향상 증거 없음
  • .kr 광고비 65%는 구글애즈, 35%만 네이버. 파워링크 이전 ≠ .kr 광고 효율 향상
  • .com 매출은 자연유입 비중 클 가능성 — 광고 끄면 매출도 일부 함께 감소 가능
  • 광고 직접 기여 매출 측정 불가 (b_conv 0) → 정확한 판단 데이터 부족

✓ 그럼에도 이전을 진행한다면

  • 사이트 통합·일원화 같은 비효율 외 이유가 있는지 확인
  • 광고 직접 기여 매출 측정 체계 먼저 구축 (b_conv 수집 복구)
  • .kr 사이트 트래픽·전환율 .com 수준 도달 가능한지 검증
  • Phase 1 소규모 광고그룹 33개로 학습 → 매출 영향 측정 후 결정
  • .com 사이트는 유지 (검색·북마크 자연유입 보존)
