3대표 의도 vs 데이터

⚠ 데이터가 보여주는 사실

  • .com이 광고비 1원당 매출 더 높음 (390% vs 282%)
  • 단순 이전 = 효율 자동 향상 증거 없음
  • .kr 광고비 65%는 구글애즈, 35%만 네이버. 파워링크 이전 ≠ .kr 광고 효율 향상
  • .com 매출은 자연유입 비중 클 가능성 — 광고 끄면 매출도 일부 함께 감소 가능
  • 광고 직접 기여 매출 측정 불가 (b_conv 0) → 정확한 판단 데이터 부족

✓ 그럼에도 이전을 진행한다면

  • 사이트 통합·일원화 같은 비효율 외 이유가 있는지 확인
  • 광고 직접 기여 매출 측정 체계 먼저 구축 (b_conv 수집 복구)
  • .kr 사이트 트래픽·전환율 .com 수준 도달 가능한지 검증
  • Phase 1 소규모 광고그룹 33개로 학습 → 매출 영향 측정 후 결정
  • .com 사이트는 유지 (검색·북마크 자연유입 보존)

6대표 미팅 결정 사항

이번 미팅에서 답 받아올 항목

  1. 광고에서 호출 트래킹 추가 — 5월 17일 광고→전화 호출 0건. .kr 페이지의 전화번호 클릭 + 광고 콜 익스텐션 트래킹 미설정. 개발 0.5~1일
  2. 광고 직접 결제 트래킹은 이미 정상 — 28일 전 기간 검증됨 (2건/13만원). 추가 작업 없음
  3. ceo-report 빌드 b_conv 복구 — API는 정상이라 빌드 스크립트만 수정. 매일 자동 측정 복구
  4. 이전 의도 재확인 — 네이버 B 파워링크 conv 복구 + 구글애즈 전환매출 트래킹. 이게 안 되면 어떤 결정도 데이터 검증 불가
  5. 이전 의도 재확인 — 효율 향상이 아니라 사이트 통합·일원화 같은 다른 이유라면 측정 없이도 진행 가능. 의도가 명확해야 함
  6. Phase 1 = 광고 일시 OFF 실험 (재정의) — 작은 광고그룹 일부를 1~2주 OFF로 두고 CS 매출 변동 추적. CS 매출 안 떨어지면 광고 기여 작은 거 → 안전하게 이전. 떨어지면 광고 효과 큰 거 → 신중하게 진행
  7. 롤백 임계치 — 광고 기여 매출 측정 불가 상태에서는 자사몰 합산 매출로만 판단. −15% 동의?
  8. Phase 3 (게시판) 결정 보류 — Phase 1·2 결과 보고 별도 회의 동의
  9. 측정 체계 ETA — .kr 사이트 gtag 수정 1~3일 (개발팀) / 검증 1주 → 약 2주면 .com·.kr 광고 ROAS 정확 측정 가능
