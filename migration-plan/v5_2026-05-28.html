결론

".kr 광고 매출 0원"은 시스템이 측정한 경로 ①만의 결과.

경로 ③ (광고 보고 → 카톡·전화 → CS 결제)는 측정 자체가 불가능하지만, 사인몰처럼 B2B 비중 큰 업종은 이 경로 매출이 클 수 있음.

즉 ".kr 광고가 효과 없다"가 아니라 "효과를 측정할 도구가 없다"가 정확한 표현.

4진짜 답을 얻는 방법

A. 측정 보강
개발팀 작업 0.5~1일
.kr 사이트의 전화번호·카톡 버튼 클릭을 측정에 잡히도록 코드 추가.

→ 광고 보고 전화 문의한 사람이 몇 명인지는 보임. 단 그 사람이 결제까지 이어진 매출 금액은 여전히 모름.
B. 광고 OFF 실험
1~2개월
.kr 광고비 일부 (예: 소액 광고 그룹 33개)를 1~2개월 일시 정지.

→ 자사몰 매출 + CS 매출이 얼마나 떨어지는지 직접 확인. 이게 가장 확실한 답.
C. 둘 다 동시에
2주 + 1~2개월
A를 먼저 적용해 측정 보강 후 B 실험.

→ 가장 정확하지만 시간 가장 오래 걸림.

6위험과 보완책

이전 시 위험

  • 광고 매출 즉시 손실 위험 — .com에서 측정된 광고 매출 472만원이 .kr에선 다시 잡힐지 모름
  • 간접 매출이 더 큼 — .com 광고 매출의 73%가 광고→며칠 후 구매. 광고 끄면 1~3개월 후 더 크게 빠질 수 있음
  • 전화·카톡 문의 매출 미상 — 측정 자체가 없어서 영향 모름
  • .com 검색 노출 자산 손실 — 수년간 쌓인 SEO 권위

보완책

  • .com 사이트는 유지 — 광고만 .kr로. 검색·북마크·단골 유입은 그대로
  • 단계적 진행 — 3단계로 학습 후 결정
  • 매출 변동 추적 — 주간 보고서로 매주 확인
  • 롤백 기준 — 자사몰 합산 매출 −15% 떨어지면 직전 단계로 복귀

7대표 결정 사항

오늘 미팅에서 답 받을 항목
1
이전 의도가 무엇인가요? "효율 향상"이라면 현재 데이터로 보장 불가. "사이트 통합·관리 일원화"라면 데이터와 무관하게 진행 가능. → 의도가 명확해야 다음 결정이 의미 있음
2
측정 시스템 보강을 먼저 할지? .kr 사이트에 전화·카톡 클릭 측정 코드 추가. 개발팀 0.5~1일. → Yes면 그 작업부터, No면 측정 없이 실험 시작
3
Phase 1 (광고 OFF 실험) 시작 시점은? 6월 1주차부터? 측정 보강 후? → 즉시 가능. .kr에 동일 상품 이미 판매 중
4
매출 떨어지면 어디까지 감수하시나요? 자사몰 합산 매출 −15%가 롤백 기준으로 적당한지. → 더 보수적(−10%) 또는 더 공격적(−25%) 선택 가능
5
Phase 3 (게시판 광고 — 광고비의 55%) 결정 보류에 동의? Phase 1·2 결과 보고 별도 회의로. → 가장 위험한 단계라 단독 결재 권장
