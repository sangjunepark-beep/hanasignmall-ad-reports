3. 작업 요청 (우선순위 순)

HTML 응답 압축 켜기 (gzip/brotli)
현재 HTML 647KB가 비압축으로 전송. mod_deflate 활성 시 약 130KB로 줄어듦 (텍스트 80% 절감).
난이도 하 · 작업량 30분 · 효과 즉효 · .htaccess 한 파일
이미지 Cache-Control 헤더 추가
현재 이미지에 max-age 없음. 재방문 시 매번 304 검증 발생. Cache-Control: public, max-age=31536000, immutable 추가 시 재방문 거의 0 요청.
난이도 하 · 작업량 30분 · 효과 재방문 시 큼 · mod_expires
이미지 WebP/AVIF 자동 변환·서빙
원본 JPG 유지하고, WebP·AVIF 사본을 같은 폴더에 함께 두기. mod_rewrite로 Accept 헤더 보고 자동 분기. 신규몰 이미지 샘플 10장 WebP 변환 시 평균 79% 절감 실측.
난이도 중 · 작업량 1~2일 · 효과 전송량 30MB → ~6MB · 디스크 약간 추가
lazy-load + picture 폴백
현재 0건 적용. 첫 화면 밖 이미지가 즉시 다 다운로드됨. native lazy + picture 태그 적용 시 첫 화면 1MB 미만으로 떨어짐.
난이도 중 · 작업량 1일 · 효과 초기 로딩 큼 · PHP 템플릿 속성 추가
첫 화면 이미지 수 축소
현재 376개 이미지 태그. carousel·탭 안 콘텐츠는 클릭 시 로딩으로 전환. UX·SEO 회귀 테스트 별도 필요.
난이도 중 · 작업량 1일 · 효과 큼 · 메인 템플릿 수정
비필수 JS/CSS 지연 로딩
외부 script 14개 중 애널리틱스·추천 위젯·소셜 공유 등 비필수는 defer/async + 첫 인터랙션 후 로딩. CSS 10개는 번들·압축.
난이도 중 · 작업량 1일 · 효과 중 · 앞 작업 대비 부수적

4. 구현 가이드

4-1. 압축·캐시 헤더 (.htaccess 또는 Apache conf)
<IfModule mod_deflate.c>
  AddOutputFilterByType DEFLATE text/html text/css application/javascript application/json
</IfModule>

<IfModule mod_expires.c>
  ExpiresActive On
  ExpiresByType image/jpeg "access plus 1 year"
  ExpiresByType image/webp "access plus 1 year"
  ExpiresByType image/avif "access plus 1 year"
  ExpiresByType text/css "access plus 30 days"
  ExpiresByType application/javascript "access plus 30 days"
</IfModule>

Header set Cache-Control "public, immutable" env=is_static
4-2. picture 태그 (PHP 템플릿)
<!-- AVIF 우선 → WebP 폴백 → JPG 최종 폴백, lazy-load 적용 -->
<picture>
  <source srcset="/gsfiles_room/2023/11/{hash}.avif" type="image/avif">
  <source srcset="/gsfiles_room/2023/11/{hash}.webp" type="image/webp">
  <img src="/gsfiles_room/2023/11/{hash}.jpg"
       loading="lazy" decoding="async"
       width="1080" height="1480" alt="상품명">
</picture>
시안·도면 이미지는 변환 제외 (견적 의사결정에 영향). 별도 디렉토리 분리 권장: /gsfiles_room/drawing/ → 변환 스크립트 --exclude drawing.
4-3. 이미지 변환 방식 선택지
방식월 비용특징
A. 일괄 변환 스크립트0원cwebp/imagemagick으로 폴더 스캔 → WebP/AVIF 생성. cron 주기 실행. 신규 업로드 훅 필수 (없으면 6개월 뒤 재발). 디스크 2~3배.
B. 서버 변환 (sharp/nginx)0원첫 요청 시 변환→캐시. CPU 약간 증가. Vary: Accept 헤더 필수.
C. 자체 imgproxy0원오픈소스. URL 파라미터로 변환·리사이즈. 원본 보존.
D. Cloudflare Polish0원 / $25Cloudflare Pro 토글만으로 자동 변환. 신규 가입 시 $25/월. 코드 변경 없음.
E. Cloudflare Images$5~$30저장+전송 종량제.
권장: A(기존 이미지 일괄 변환) + B(신규 업로드 자동 변환) 조합. Cloudflare 신규 가입은 불필요.
