신규몰(.kr) 고객동선 개선요청

개발팀 전달용 · 네이버 파워링크(모바일 유입) 고객 관점 · 구몰(고도몰5 / m.hanasignmall.com) 대비 · 2026-06-01 점검
배경 — .com 파워링크 광고를 .kr(신규몰)로 이전 검토 중. 광고 클릭은 대부분 모바일이고, 사인물은 전화·카카오톡 상담 → 주문 비중이 큰 업종. "광고를 옮기기 전에 .kr이 모바일 광고 랜딩으로서 문제가 없는지"를 먼저 점검함. 아래는 실제 두 사이트를 모바일 환경(iPhone Safari UA)으로 받아 직접 측정·교차검증한 결과와 구체적 개선 방향.

문제점 + 개선 방향 (심각도순)

각 항목: 현상 / 구몰 비교 / 왜 중요 / 구체적 개선 방향(방법·기준·예시·목표). 모두 모바일 광고 유입 고객 기준.
심각 상1. 모바일 페이지가 너무 무거움 — 광고 이탈 직결
신규몰 현상모바일 메인 HTML 910KB, 메인 이미지 태그 493개. 게시판 상세 로드 시 리소스 233개·전송량 약 47.8MB·load 완료 5.5초. 800KB대 비최적화 상세 이미지 다수.
구몰은모바일 접속 시 m.hanasignmall.com 전용 사이트로 302 분기. 메인 134KB·이미지 78개.
왜 중요광고는 클릭당 과금. LTE에서 47MB·5.5초면 첫 화면 전에 이탈 → 광고비만 쓰고 전환 0. .kr 광고 직접매출 0의 유력 원인.
개선 방향
① 상세 이미지 포맷·용량 표준화 — 상품 상세 long-image를 WebP로 변환(JPG 대비 25~35% 감량), 폭 max 1080px로 리사이즈, 장당 200KB 이하 목표. 기존 800KB대 → 일괄 배치 변환.
② lazy-load 적용 — 첫 화면 밖 이미지는 지연 로딩. 상세 long-image는 화면 진입 시 순차 로딩(아래 예시).
<!-- 상세 이미지: 네이티브 lazy-load + 비율 고정으로 CLS 방지 -->
<img src="/data/goods/47202_detail_01.webp"
     loading="lazy" decoding="async"
     width="1080" height="1480" alt="홀로그램 주차스티커 상세">
③ 메인 이미지 개수 축소 — 493개 → 첫 화면 노출분만 즉시 로딩, 나머지 carousel/탭 콘텐츠는 클릭 시 로딩(지연).
④ 정적 리소스 캐시·압축 — 이미지 CDN 또는 서버 Cache-Control: max-age 30일, gzip/brotli 적용, HTTP/2 유지.
⑤ 광고 랜딩 경량 모드(선택) — 파워링크 유입(utm 파라미터 감지) 시 핵심 정보(대표이미지·가격·상담버튼·주문옵션)만 먼저 렌더, 부가 콘텐츠 후순위.
목표 — 광고 랜딩 상품 페이지 모바일 LCP 2.5초 이내, 첫 화면 표시 3초 이내, 상세 총 전송량 47MB → 10MB 이하.
난이도 중 · 효과 최상 · 광고 이전 전 1순위
심각 상2. 모바일에 전화·카톡 상담 진입구가 없음 — CS 주문 경로 차단
신규몰 현상모바일 메인에 작동하는 tel: 클릭통화 0건. 번호(032-468-7162, 1644-7523)는 텍스트로만 → 탭해도 전화 안 걸림. 카카오 상담 링크도 메인엔 없고 우측 챗봇 위젯에만 의존. 상세 tel은 tel:16447523(하이픈 없는 비표준).
구몰은모바일 전 페이지 상단에 "카카오톡 ID: 하나사인몰 [상담하기]" 상시 + href="tel:1644-7523" 클릭통화 일관. 카카오 채널(pf.kakao.com) 정상.
왜 중요사인물은 주문제작·규격·시공 문의가 많아 전화·카톡 → CS 결제 비중 큼. 광고를 .kr로 옮기면 클릭은 가는데 상담 입구가 약해 CS 전환까지 끊길 위험. (적자·본전 광고가 CS 매출 입구일 수 있다는 우려와 직결)
개선 방향
① 모바일 하단 고정 상담바(sticky CTA) — 전 페이지 화면 하단에 전화걸기 / 카카오톡 상담 2버튼 항상 노출. 스크롤 무관 고정.

  <a href="https://pf.kakao.com/_하나채널ID/chat">💬 카톡상담</a>
</div>

② tel 표기 표준화 — 사이트 전역 전화번호를 tel:1644-7523 형식으로 통일(하이픈 포함). 텍스트 번호도 모두 a href 처리.
③ 카카오 채널 연결 — 구몰이 쓰는 카카오 채널(pf.kakao.com/_하나채널)을 신규몰에도 동일 연결. 상담 유입을 한 채널로 합산 관리.
④ 상품 상세 내 상담 버튼 — 주문제작 상품은 "구매하기" 옆에 "규격·시안 문의" 버튼(전화/카톡) 병치. 이미 있는 "실시간 전문상담원 상담하기"를 전화·카톡과 묶어 노출.
⑤ 상담 유입 추적 — 상담바 클릭에 이벤트 파라미터(어느 상품·광고에서 눌렀는지) 부착 → 추후 "광고→상담→CS결제" 경로 측정 기반 마련.
목표 — 모바일 전 페이지에서 2탭 이내 전화·카톡 도달. 광고 적자로 보이던 그룹의 CS 기여를 측정 가능하게.
난이도 하 · 효과 최상 · 광고 이전 전 1순위
심각 중3. 반응형 단일 페이지 — 무게 문제가 모바일에 그대로 전가
신규몰 현상모바일 UA로도 같은 URL·같은 페이지 반환(반응형). viewport meta는 정상이나 1번의 무게가 모바일에 경량화 없이 노출. 외부 script 25개·stylesheet 11개.
구몰은모바일 전용(m.) 별도 운영으로 모바일 맞춤 경량 제공.
개선 방향
① 모바일 조건부 로딩 — 반응형 구조 유지하되, PC 전용 위젯/슬라이더/대형 배너는 모바일에서 로드 자체를 스킵(CSS display:none만으로는 다운로드가 일어나므로 JS 조건 분기로 미주입).
② script 통합·지연 — 외부 script 25개 중 비필수(애널리틱스·위젯)는 defer/async + 첫 인터랙션 후 로딩. CSS 11개는 빌드 시 번들·압축.
③ 공통 컴포넌트화 — 상담바·헤더·가격박스 등을 공통 모듈로 빼서 PC/모바일 분기 유지비 최소화.
④ (대안 검토) — 단기 개선이 한계면, 구몰처럼 광고 랜딩용 모바일 경량 템플릿 별도 운영도 옵션. 단 유지보수 이중화 부담 고려.
목표 — 모바일 초기 로딩 리소스(JS/CSS) 30% 이상 감축. 1번 목표와 연동.
난이도 중 · 효과 중
양호4. 검색·필터·배송표기는 신규몰이 양호 (유지)
확인됨"주차스티커" 검색 시 45~47건 + 카테고리 패싯 + EASY서치 필터(업종/소재/디자인/두께/사이즈) 정상. 배송정보(무료배송/제주·도서 +6,000원/배송 14일) 명확. 강제 회원가입 없음. 이 부분은 손댈 필요 없음.
유지 권고1·2번 개선 시 이 검색·필터 UX는 그대로 보존. 경량화 과정에서 필터 동작 깨지지 않게 회귀 테스트.
