신규몰(.kr) 고객동선 개선요청

개발팀 전달용 · 모바일 광고 유입 동선 점검 · 2026-06-01 (v2: 측정 정정 + 수용기준·회신요청 추가)
배경 — .com 파워링크 광고를 신규몰(.kr)로 이전 검토 중. 광고 클릭은 모바일 중심이고, 사인물 업종 특성상 매출의 90%가 전화·카톡 상담 주문(CS). 광고 이전 전에 .kr이 모바일 광고 랜딩으로서 무리가 없는지 점검한 결과와 개선 방향입니다. 본 문서는 모바일 UA(iPhone Safari)로 양쪽 사이트를 직접 측정한 결과 기반입니다.
이 문서가 의도하지 않는 것 — "지금 .kr이 부족하다"는 책임 추궁이 아닙니다. 광고 이전 전 모바일 유입 동선을 함께 다듬자는 협업 요청입니다. 우선순위·일정·구현 방식은 개발팀 의견에 따라 조정합니다.

문제점 + 개선 방향 (심각도순)

각 항목: 현상 → 비교 → 영향 → 개선 방향. 모두 모바일 광고 유입 기준.
심각 상1. 모바일 페이지 무게 — 광고 이탈 가능성
현상모바일 도메인(m.hanasignmall.kr) 메인 HTML 647KB, 메인 이미지 태그 376개. 상품 상세에 비최적화 long-image 다수 존재.
구몰 비교m.hanasignmall.com 메인 130KB / 이미지 78개. 모바일 전용 페이지로 경량.
영향광고 클릭당 과금 환경에서 첫 화면 진입 전 이탈 가능. 유력 가설 중 하나이며 단정은 아닙니다(LCP·이탈률 실측은 GA/RUM 데이터 별도 확인 필요).
개선 방향
① 상세 이미지 표준화 (상품유형 분기) — 일반 상품 상세 long-image는 WebP·max 1080px·200KB/장 목표. 단, 시안·도면·실측 이미지가 견적 의사결정에 직접 영향인 상품은 원본 해상도 유지(상품 마스터에 유형 플래그 권장).
② lazy-load — 첫 화면 밖 이미지는 native lazy + 비율 고정으로 CLS 방지.

③ 메인 이미지 수 축소 — 376개 → 첫 화면 노출분만 즉시 로딩, carousel/탭 콘텐츠는 클릭 시 로딩.
④ 정적 리소스 캐시·압축 — 이미지 CDN 또는 Cache-Control: max-age 30d, gzip/brotli, HTTP/2.
⑤ 광고 랜딩 경량 모드 (선택) — utm 파라미터 감지 시 핵심 정보(대표이미지·가격·상담·옵션)만 우선 렌더.
목표 — 광고 랜딩 페이지 모바일 LCP 2.5초 이내, 상세 총 전송량 직전 대비 −30%.
난이도 중 · 효과 큼 · 광고 이전 병행 가능
심각 상2. 모바일 메인에 전화·카톡 상담 진입구 부재 — CS 주문 경로 약화
현상모바일 메인에 tel: 클릭통화 링크 0건. 번호는 텍스트로만 표기. 카카오 상담은 우측 챗봇 위젯에 한정. 상세의 일부 tel은 tel:16447523(하이픈 없음, 비표준 표기).
구몰 비교모바일 전 페이지 상단 카카오 상담 + tel:1644-7523 클릭통화 일관 적용.
영향사인물 주문은 규격·시안·시공 문의가 많아 전화·카톡 → CS 결제 비중 큼. 광고 .kr 이전 시 상담 진입이 약하면 CS 전환까지 약화 가능.
개선 방향
① 모바일 하단 고정 상담바 (sticky CTA) — 전 페이지 화면 하단에 전화 / 카톡상담 2버튼 상시 노출.

② tel 표기 표준화 — 전역 tel:1644-7523(하이픈 포함)으로 통일, 텍스트 번호도 모두 a href 처리.
③ 카카오 채널 — 합산 아님, 라우팅·태깅 설계 선행 — 채널별(.com / .kr / 스마트스토어)로 상담 출처가 구분 가능한 태깅이 우선. 합쳐버리면 채널 효율 판단·해피톡 분석이 오염됩니다. 합산 여부·운영 방식은 웹팀과 별도 협의.
④ 상품 상세 내 상담 CTA — 주문제작 상품은 "구매하기" 옆에 "규격·시안 문의" 버튼(전화/카톡) 병치. 사인물 특화 동선(시안 업로드·도면 첨부·견적 폼)은 본 문서 범위 외, 별도 기획.
⑤ 상담 진입 추적 — 상담바 클릭에 이벤트 파라미터(상품·광고 출처) 부착 → "광고 → 상담 → CS 결제" 측정 기반 마련.
목표 — 모바일 전 페이지에서 2탭 이내 전화·카톡 도달. 광고 적자로 보이던 그룹의 CS 기여 측정 가능화.
난이도 하 · 효과 큼 · 광고 이전 전 1순위 (핫픽스 권장)
심각 중3. 모바일 도메인은 있으나 경량화는 부족
현상m.hanasignmall.kr 모바일 도메인 실재(JS 리다이렉트). 다만 메인 647KB로 구몰 m.도메인(130KB)의 약 5배. script 15개·stylesheet 11개.
구몰 비교m.hanasignmall.com이 모바일 맞춤 경량 콘텐츠로 분리 운영.
영향도메인은 있으나 콘텐츠 무게 그대로 → 모바일 체감 동일.
개선 방향
① 모바일 조건부 로딩 — PC 전용 위젯/슬라이더/대형 배너는 모바일에서 로드 자체 스킵(display:none만으론 다운로드 발생).
② script 통합·지연 — 비필수 script는 defer/async + 첫 인터랙션 후 로딩. CSS 11개는 빌드 시 번들·압축.
③ 공통 컴포넌트화 — 상담바·헤더·가격박스 공통 모듈 → PC/모바일 분기 유지비 최소화.
목표 — 모바일 초기 로딩 JS/CSS 30% 이상 감축. 1번과 연동.
난이도 중 · 효과 중
양호4. 검색·필터·배송표기는 신규몰 양호 (유지 권고)
확인됨"주차스티커" 검색 45~47건 + 카테고리 패싯 + EASY서치 필터(업종/소재/디자인/두께/사이즈) 정상 동작. 배송정보(무료배송·제주 도서 +6,000원·배송 14일) 명확. 강제 회원가입 없음. 이 부분은 손댈 필요 없음.
유지 권고1·2번 개선 시 위 UX 보존. 경량화 과정에서 필터 회귀 테스트 필수.
